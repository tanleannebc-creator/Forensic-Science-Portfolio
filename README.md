# Forensic-Science-Portfolio
A developing portfolio of forensic toxicology and analytical science projects using R/Python, created alongside applications for MSc forensic science and graduate laboratory roles.

I am a final-year Medical Biochemistry BSc student with interest in forensic science, toxicology, analytical chemistry and evidence-based laboratory work. This portfolio is being built to demonstrate my ability to apply scientific reasoning, data analysis and interpretation to forensic and toxicological problems.

**Current Projects**

**Project 1: Forensic Toxicology Drug Screening**

A simulated toxicology screening project exploring how analytical results can be interpreted against detection thresholds. This project demonstrates basic data handling, concentration analysis, visualisation, and forensic interpretation.

Skills demonstrated:
Data cleaning
Threshold-based interpretation
Toxicology reporting
R/Python analysis
Scientific communication

**Project 2: Blood Alcohol Concentration Modelling**

A developing project modelling blood alcohol concentration over time and interpreting how body mass, alcohol intake, and metabolism rate affect toxicological interpretation.

Skills demonstrated:

Toxicokinetic modelling
Data visualisation
Interpretation of uncertainty
Forensic case-style reporting

**Project 3: Forensic Evidence Classification**

A developing project using sample features to classify evidence types and demonstrate basic statistical and machine learning approaches relevant to forensic interpretation.

Skills demonstrated:

Classification
Pattern recognition
Data visualisation
Evidence interpretation
Reproducible analysis

**Academic Background**

My academic background is in Medical Biochemistry, including laboratory experience with analytical and biochemical techniques such as chromatography, UV-Vis spectrophotometry, spectrofluorometry, protein analysis, and molecular biology methods.

**Career Aim**

My aim is to progress into forensic science, forensic toxicology, or analytical laboratory work, with particular interest in the interpretation of biological and chemical evidence.
